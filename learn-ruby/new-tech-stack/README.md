# Desafio Técnico — IUUPI

Este repositório contém um desafio técnico para avaliação de conhecimento na vaga de desenvolvedor na **IUUPI**.

## Objetivo
Evoluir a aplicação para:
- Listar pokémons e suas informações consumindo a **PokeAPI** (https://pokeapi.co);
- Permitir **busca** e **paginação**;
- Permitir adicionar um pokémon selecionado ao **seu time pokémon**.

## Ruby
A versão utilizada no sistema é **Ruby 3.3.5**. Recomenda-se instalar usando um gerenciador de versões como **RVM**, **rbenv** ou **mise**.

## Requisitos do time pokémon
O time deve:
- Ter **todas as ações CRUD** (criar, listar, editar/atualizar e remover);
- Ter **no máximo 6 pokémons**.

## Entrega
- **Data limite:** até **meia-noite do sábado 14/03/26**.
- Você deve **fazer um fork** deste repositório e, ao finalizar, **enviar o link do seu repositório** com a solução para este link: [Formulário](https://forms.gle/KKD7yn6nCUzKFbrX9).

## Restrições
- **Não utilizar IA** durante o desenvolvimento. O propósito é testar seu conhecimento e habilidades, não do ChatGPT.
- **Não adicionar gems** além das já listadas no projeto, **exceto** gems de apoio como **`faraday`** ou **`pagy`**.
- **Não remover** gems do projeto ou alterar o banco de dados (SQLite).
